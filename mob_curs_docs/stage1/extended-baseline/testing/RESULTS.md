## Reproduction

Requires an existing Android SDK with this project's platforms, JDK 21, PowerShell 5.1, Git, and the repository's Gradle wrapper. No global tools are installed. JaCoCo dependencies are resolved through Gradle.

```powershell
.\measure.ps1 -Repository <repository> -JavaHome <jdk-21> -AndroidSdk <android-sdk> -TempRoot <approved-existing-temp-directory> -Repetitions 5
.\summarize.ps1
```

Run from this evidence directory, substituting local arguments; do not publish machine-specific arguments. `measure.ps1` creates a unique temporary directory, extracts `git archive HEAD`, and only builds that copy. Uncommitted changes and machine-local configuration are not copied. If reproducing later, use a checkout at the recorded revision. The init script is supplied externally with `-I`; no production, test, or build configuration file in the original checkout is edited.

Each invocation uses `--no-build-cache`; the unit Test task additionally sets `outputs.upToDateWhen { false }` and `outputs.cacheIf { false }`. This ensures it executes on all repetitions without `--rerun-tasks`, which would force all compilation dependencies too. Sanitized `tasks-run-1.txt` through `tasks-run-5.txt` prove the actual Test task runs without `UP-TO-DATE` or `FROM-CACHE`. Repeated Kotlin production/test compilations are `UP-TO-DATE`. `baselineCoverage` is also executed each time. Gradle exits zero because failure ignoring is measurement-only; the CSV records actual test failures and must be used to judge test success.

Runtime: Zulu OpenJDK 21.0.13+9-LTS, Windows, Gradle wrapper from snapshot, JaCoCo 0.8.14. Test timings include JaCoCo agent overhead. Wall times include Gradle configuration/reporting and shared-host contention, and are not controlled performance benchmark results. The 59.480-second third invocation is retained rather than discarded; its 4.872-second test-case total does not show a corresponding test-body slowdown.

## Evidence and Limits

- `coverage-run-1.xml` through `coverage-run-5.xml`: detailed counters, package/class/source details; machine session IDs and external DTD removed without changing counters.
- `runs.csv`, `test-cases.csv`, `summary.json`: repeat outcomes, durations, per-test failure rates and package/aggregate coverage.
- `tasks-run-*.txt`: allowlisted task execution/status evidence only.
- `metadata.json`, `coverage.init.gradle`, `measure.ps1`, `summarize.ps1`: revision/runtime/tool versions and reproducible measurement procedure.
- Raw Gradle/JUnit logs, binary execution data, absolute machine paths and machine session IDs remain only in the private temporary snapshot and are not included here.

These measurements close the missing baseline **local unit line/branch coverage and repeated-unit stability observations**. They do not assert passing tests, device/UI coverage, randomized-order robustness, or production readiness. No emulator interaction, commit, push, or application/test/build-configuration change was performed.
